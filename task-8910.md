On the back burner since 2026-10-27, after lesson 7. Nothing here is started.

## 8. Make lookups into streams

**Why.** Lesson 7 measured a random lookup at 10 to 50 times the cost of a
streamed element out of cache (40 to 95 ns a contact against 2 to 4 ns a body
from RAM), and found that making lookups less random beats any layout choice.

**What.**

- A uniform spatial grid: cell size, cell index from position, entities
  sorted by cell each frame (counting sort), a start offset per cell.
- kayan's collision rewritten from every bullet against every drone into a
  walk over the bullet's cell and its neighbours.
- Measured: the nested loop against the grid, at the game's size and at
  thousands of entities; the cost of the sort itself.
- The same output as lesson 6, byte for byte, so `.expected` proves the grid
  finds the same hits.

**Checkable here:** everything. All rin, no platform code.

## 9. Parallel systems

**Why.** The second payoff of an ECS: systems already say which columns they
read and which they write.

**What.**

- A scheduler that runs systems whose write sets do not overlap at the same
  time, from their column lists.
- Splitting one system's tables, or one table's rows, across threads.
- False sharing: two threads writing neighbouring rows in the same cache
  line, measured.
- Why lesson 6's command buffer is what makes this safe: no structural change
  while systems run.

**Checkable here:** with pthreads on Linux. Win32 threads need a run on
Windows.

## 10. Hand-written SIMD in rasm

**Why.** The raw SIMD rasm is for, next to what the compiler writes.

**What.**

- `move_split`'s integrate kernel written by hand in rasm, SSE then AVX2, and
  linked into a rin program next to the compiler's version, with timings.
- A kernel the compiler does badly: the `vec3` shuffle case, or gathering
  bodies for contacts, where hand-written code should win.
- Reading the compiler's loop line by line against the hand-written one.

**Checkable here:** assembly and object code only. Running it needs Windows.
